##requisitos

PHP > 8.3
Mysql > 8.0
Composer


##Como rodar o projeto baixado

composer install


##Sequencia para criar o porjeto
Criar o arquivo composer.json com a instrução básica.
```
composer init
```

##Como usar o GitHub

Sobre a autenticacao via token:

https://www.alura.com.br/artigos/nova-exigencia-do-git-de-autenticacao-por-token-o-que-e-o-que-devo-fazer


##Definir as configurações do usuário
```
git --config --local user.name Paulo

git --config --local user.email paulo-sgo@hotmail.com
```

Baixar os arquivos do Git.

```
git clone --branch <nome> <url_repotirory>

git brahcn  obs: deve estar na dev_master
```

Baixar as atualizações
```
git pull

```

Adiconar todos os arquivos modificados no staging area - ára de preparação
``
git add .

git commit -m "descrição do commit"


git push origin dev-master
```
